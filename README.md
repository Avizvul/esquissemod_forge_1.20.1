# Esquisse Mod (Forge 1.20.1)

A functional sketchbook for Minecraft: draw right in the game, tear out pages, hang them on walls and print copies.

Мод для Minecraft: скетчбук, в котором можно рисовать прямо в игре, отрывать страницы, вешать их на стены и печатать копии.

## Возможности

- Скетчбук на 16 страниц, инструменты: карандаш, цветной карандаш, маркер, ластик, клячка, растушёвка, линейка, циркуль, лупа, текст и штампы
- Оторванные страницы с подписью и авторством, размещение на стенах, полу и потолке
- Альбом для рисунков и пенал для инструментов
- Принтер: копии страниц и экспорт рисунка в PNG

## Установка

Нужны Minecraft 1.20.1 и Forge 47 или новее. Положите jar мода в папку `mods` на клиенте и на сервере: мод обязателен с обеих сторон.

## Сборка

Нужен Java 17, Gradle скачает его сам, если JDK не установлен.

```bash
./gradlew build
```

Готовый jar появится в `build/libs`. Для запуска из исходников есть задачи `runClient` и `runServer`. Клиент работает в папке `run-client`, сервер в `run`.
